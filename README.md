# Programación III

Repositorio con trabajos prácticos, ejercicios y proyectos desarrollados durante la cursada de **Programación III** en la carrera de Ingeniería Informática.

El objetivo de este repositorio es almacenar y documentar las implementaciones realizadas durante la materia, aplicando conceptos de programación avanzada, estructuras de datos y resolución de problemas algorítmicos.

---

## 📚 Contenidos

Este repositorio incluye distintos ejercicios y prácticas relacionados con:

- Programación orientada a objetos
- Manejo de estructuras de datos
- Implementación de algoritmos
- Resolución de problemas computacionales
- Organización de proyectos en Java

---

## 🛠 Tecnologías utilizadas

- **Java**
- **Git**
- **GitHub**
- **IntelliJ / VS Code** (según práctica)

---

## 📂 Estructura del repositorio

El repositorio está organizado en carpetas que contienen los distintos trabajos prácticos y ejercicios realizados durante la cursada.
